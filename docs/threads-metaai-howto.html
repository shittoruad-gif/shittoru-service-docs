Meta AI呼びかけ投稿のやり方（実際の画面）

Threads Studio 公式LINEに毎朝10時に届く「今日のMeta AI呼びかけ投稿」の使い方です。やることは2つだけです。画面はすべて実際のThreadsアプリのものです。

やることは2つ

1LINEの緑のボタンを押す

公式LINEに届いたカードの「Threadsアプリで投稿する」を押します。Threadsアプリが開き、文章はもう入っています。

2Threadsで「投稿する」を押す

開いた画面の上に出ている名前が、自分のお店のアカウントであることを確かめて、右下の「投稿する」を押します。「@meta.ai」が青くなっていれば正しい状態です。

別のアカウント名が出ているときは、いったんキャンセルし、Threadsアプリの右下の人型アイコンからお店のアカウントに切り替えて、もう一度LINEのボタンを押してください。

そのあと、どうなるか

投稿しました、と出る

画面の下に「投稿しました」と出れば完了です。ここで閉じて構いません。

約1分でMeta AIの返事が付く

投稿の下に、Meta AI（青いチェックの meta.ai）がお店の名前を出して答えます。この例では、投稿から1分ほどで「浅口・金光・鴨方エリアでピラティスを探している方へ、Moveactの強みはこれです」と3点にまとめた紹介が付きました。

Meta AIとは何か・なぜ使うのか

Meta AIは、InstagramやThreadsを運営するMeta社のAIアシスタントです。Threadsの投稿で「@meta.ai」と呼びかけると、公開のコメントで答えます（2026年9月から日本でも利用可）。
お店の名前を出して答えてくれる「〇〇で整体院のおすすめを教えて」と聞くと、あなたのお店の名前入りで紹介文のように答えます。自分で宣伝するより、第三者に紹介された形で読まれます。
会話が付いた投稿は表示が伸びるMeta AIの返事が付くと投稿の下に会話ができ、Threadsはそういう投稿を多くの人に見せます。Moveactの実測では、通常の投稿が数十〜百数十回の表示だったのに対し、呼びかけ投稿は数百〜二千回の表示になりました。
地元の人に届く地域名（駅名・町名）を入れて聞くので、その地域の人に届きやすくなります。
宣伝に見えない質問の形なので、売り込みではなく「聞いてみた」投稿として自然に読まれます。
注意：@meta.aiはThreads側で段階的に提供されており、まだ使えないアカウントでは返事が付きません。Meta AIの答えは不正確なことがあります。お店の事実と違う内容があれば、その返事に返信して正しい内容を書いてください。

自分で打って投稿する場合

「@」を打つと meta.ai が候補に出る

投稿画面で「@」を打つと候補が出ます。青いチェックの「meta.ai（Meta AI）」を選ぶと、メンションとして入ります。そのあとに、お願いしたい文章を続けます。

文の形の例

・〇〇駅周辺の人に、うちのお店（店名）を届けて
・〇〇で整体院のおすすめを教えて
・〇〇で肩こりに悩む人に、整体院に通うメリットを伝えて
・うちのお店（店名）の強みを、来店されたことのない人に伝えて
・店名の整体は、他のお店と何が違う？

地域は市より細かく（駅名・町名）。数字や実績は事実だけを入れます。

なぜ自動投稿ではなく、アプリから出すのか

Threads Studioの自動投稿（API）から「@meta.ai …」を出すと、Threadsの仕様で@meta.aiがメンション（青いリンク）にならず、Meta AIは返事をしません（2026年9月6日に実測。自動投稿8件は返事0、アプリからの投稿16件は全件に返事）。そのため、この1件だけはボタンからThreadsアプリで投稿していただく形にしています。毎日の自動投稿はご契約の本数どおりで、呼びかけ文はサービスとしてプラス1回です。自動投稿からも効くようになった時点で、1日の本数の中に含める形に切り替えます。
