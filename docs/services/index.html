始める前に、よく聞かれること

どれから始めればいいか分かりません

このページの「1分診断」で目安が出ます。迷ったら無料相談で、いまの状況を伺ってから一緒に選びます。全部を一度に始める必要はありません。

ひとつだけ申し込むこともできますか？

できます。どのサービスも単体でご利用いただけます。あとから組み合わせることもできます。

治療院やサロン以外のお店でも使えますか？

Threads Studio・Instagram広告・マカセル・LP制作・Keiro・口コミ作成アプリは、飲食店・教室・物販など店舗全般でお使いいただけます。交通事故コンサルティングと月刊 HANDS NOTE は治療院向けです。

パソコンが苦手です。使いこなせますか？

Threads Studio は公式LINEの中だけで操作が終わります。アカウントの準備や初回の設定は、こちらで代わりに行うか、Zoomで一緒に進めます。

契約期間の縛りや、解約の条件は？

サービスごとに異なります。Threads Studio・マカセル・Keiro・Instagram広告 運用代行は契約期間の縛りがありません。LP制作は12か月、サロンカルテは最低6ヶ月のご契約です。くわしくは各サービスのページをご覧ください。

月額以外にかかる費用はありますか？

広告費（Meta社へ直接お支払い）、LINE公式アカウントの月額・配信料金（LINEヤフー社へお支払い）、独自ドメインなどの実費は別途かかります。無料相談で総額をご案内します。

成果は保証されますか？

集客の成果をお約束することはできません。そのかわり、どこで止まっているかを数字で見えるようにし、効いていないところを一緒に直していきます。
