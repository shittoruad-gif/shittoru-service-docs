1

Threadsとは何か、を知る

読むだけ／2分

Threads（スレッズ）は、文章を中心に投稿するSNSです。Instagramを運営している会社が作りました。

  • 写真が主役のInstagramに対して、Threadsは文章が主役です
  • フォロワーが0人でも、投稿が見知らぬ人に届きます。「同じような話題に興味がある人」へ自動的に表示される仕組みだからです。ここが集客に向いている理由です
  • Threadsを使うにはInstagramのアカウントが必要です。Threads単独では始められません
Threads Studioがすること：このThreadsへの投稿を、毎日AIが代わりに書いて、自動で出します。先生は届いた文章を見て「これでよい」と押すだけです。
2

Instagramのアカウントを作る

所要 5分／すでにお持ちの方はSTEP3へ

Threadsの土台になります。お店用に1つ作ってください。

  1. スマートフォンでApp Store（iPhone）またはGoogle Play（Android）を開く
  2. 「Instagram」と検索して、アプリを入れる（無料です）
  3. アプリを開き、「新しいアカウントを作成」を押す
  4. メールアドレスまたは電話番号を入れ、届いた確認番号を入力する
  5. パスワードと誕生日を入れる
  6. ユーザーネームを決める（半角の英数字。お店の名前と地域が分かるものにしてください）
  7. プロフィール写真に、お店の外観かロゴを設定する
できたかの確認　右下のアイコンを押して、自分のプロフィール画面が出れば完了です。
ご家族と共用している個人のアカウントは使わないでください。お店の投稿と私生活の写真が混ざってしまいます。お店専用に新しく作ることをおすすめします。
3

Threadsのアカウントを作る

所要 3分／ここでつまずく方がいちばん多いところです

Instagramを持っているだけでは、Threadsのアカウントはまだありません。Threadsアプリで一度だけ作る作業が必要です。ここが終わっていないと、あとの「Threads連携」が進みません。

  1. スマートフォンでApp StoreまたはGoogle Playを開く
  2. 「Threads」と検索して、アプリを入れる（無料です。アイコンは黒地に白い「＠」のような記号）
  3. アプリを開くと、そのスマートフォンでログイン中のInstagramアカウントが表示されます。お店のアカウントを選んで「ログイン」を押す
  4. 「Instagramからプロフィールをインポート」と聞かれます。そのまま引き継いで構いません
  5. 「公開プロフィール」を選ぶ（重要）
  6. 最後に「Threadsに参加する」などのボタンを押して完了です
できたかの確認　Threadsアプリの右下のアイコンを押して、自分のプロフィール（ユーザーネームが表示された画面）が出れば完了です。ここが出ないうちは、まだアカウントができていません。
「非公開」にしないでください。非公開にすると、フォロワー以外の方に投稿が届きません。集客のための発信ができなくなります。あとから変えるときは、Threadsの設定の「プライバシー」から切り替えられます。
Instagramを複数お持ちの方へ：Threadsアプリの画面上部でアカウントを切り替えられます。お店用のアカウントで作ってください。ここで選んだアカウントが、そのままThreads Studioにつながります。
4

Threadsのプロフィールを整える

所要 5分

投稿を見た方が、次に見る場所です。ここが空だと、興味を持たれても来店につながりません。Threadsアプリの右下のアイコン →「プロフィールを編集」から設定します。

  • 名前：お店の名前と地域（例：〇〇整体院｜岡山市北区）
  • 自己紹介：どんなお悩みの方が来ているか、営業時間、定休日
  • リンク：公式LINEの友だち追加URL、またはご予約ページ
できたかの確認　自分のプロフィールを開いて、名前・自己紹介・リンクが表示されていれば完了です。
公式LINEのURLは、このあとThreads Studioにも登録します。固定投稿のコメント欄に自動で付き、集客の入口になります。お手元にご用意ください。
運用編STEP 5 - 10　Threads Studioの設定

ここからの設定は、公式LINEのトークからでもアプリの画面からでも進められます。どちらか一方だけで大丈夫です。スマートフォンだけで終わる公式LINEをおすすめしています（Threadsの連携だけはパソコンが確実です）。

Threads Studioに会員登録する

所要 3分

  1. https://threads-studio.com を開く
  2. お名前・店舗名・メールアドレス・パスワードを入力する
  3. 紹介コードをお持ちの方は、そのまま入力する（お持ちでなければ空欄）
  4. 登録すると料金プランの画面が開きます。プランを選んでお申し込みください
できたかの確認　ホーム画面が開き、ご契約中のプラン名が表示されていれば完了です。
お支払いのとき、メールアドレスはこの登録と同じものをご入力ください。違うアドレスだと、お支払いとアカウントが自動で結びつかず、有料機能が使えないままになります。

公式LINEとつなぐ

所要 2分

会員のアカウントと公式LINEを結び付けます。どちらから始めても結果は同じです。

公式LINEから おすすめ
  1. Threads Studioの公式LINEを友だち追加する
  2. トーク下のメニューで「登録済みの方はこちら」を押す
  3. 会員登録に使ったメールアドレスを、そのまま送る
  4. 届いた6桁の番号をトークに送る（10分間有効）
アプリから
  1. 左メニューの「設定」を開く
  2. 「LINEで通知を受け取る」の「LINE連携をはじめる」を押す
  3. 表示される「友だち追加する」から友だち追加する
  4. 画面に出た6桁のコードをトークに送る（10分間有効）
できたかの確認　トークの下のメニューが、6つのボタン（今日の投稿・コメント・設定・投稿の成績・固定投稿・お店とアカウント）に変わっていれば完了です。
番号が届かないときは、会員登録と同じアドレスを送っているか、迷惑メールフォルダに入っていないかをご確認ください。

「はじめの設定」に答える

所要 10〜15分／全18問

お店のことを順番におうかがいします。答えた内容だけをAIは事実として使います。書いていない実績・料金・数字が投稿に出ることはありません。

実際に聞かれるのは、たとえばこのような質問です。

  • どんな業種ですか？
  • お店がある場所を、できるだけ詳しく教えてください
  • 一番来てほしいのは、どんなお客さんですか？
  • そのお客さんは、どんなことで困っていますか？
  • 他のお店ではなく「あなたのお店」を選ぶ理由・強みは何ですか？
公式LINEから おすすめ
  1. メニューの「はじめの設定」を押す
  2. 「お店の集客」か「個人にファンをつける」かを選ぶ
  3. 届く質問に、トークで順番に答える
アプリから
  1. ホームの「セットアップ状況」で「お店の情報を登録」の「登録する」を押す
  2. 「お店の集客」か「個人にファンをつける」かを選ぶ
  3. 画面の質問に順番に答える
できたかの確認　最後まで答えると確認画面が出ます。ホームの「セットアップ状況」で「お店の情報を登録」に完了が付いていれば大丈夫です。
途中で手を止めても、それまでの回答は残ります。あとで「はじめの設定」を押すと「続きから」を選べます。あとから直すときは、LINEの「お店の情報」／アプリの左メニュー「お店の情報を修正」から変更できます。

Threadsアカウントを連携する

所要 3分／パソコンからがおすすめです

STEP3で作ったThreadsに、投稿する権限をつなぎます。

その前に確認してください。Threadsアプリを開いて、右下のアイコンから自分のプロフィールが表示されますか？ 表示されない場合、Threadsのアカウントがまだできていません。STEP3に戻ってください。ここを飛ばすと、連携画面から先へ進めません。
公式LINEから
  1. メニューの「お店・アカウント」を押す
  2. 「Threadsアカウントの連携」を選ぶ
  3. 届いたリンクを開き、「Threadsと連携する」を押す
  4. Threadsの画面で内容を確認し、「許可」を押す
アプリから こちらが確実
  1. 左メニューの「Threads連携」を開く
  2. 「Threadsと連携する」を押す
  3. Threadsの画面で内容を確認し、「許可」を押す
できたかの確認　連携画面に、つながったアカウント名（@から始まる名前）が表示されれば完了です。
スマートフォンだと、うまく戻れないことがあります。Threadsアプリに画面が切り替わってしまい、そのまま止まってしまう症状です。その場合はパソコンのブラウザで threads-studio.com を開いて、同じ手順をお試しください。パソコンだと確実です。

固定投稿を作って、ピン留めする

所要 5分／集客のいちばん重要な工程

固定投稿とは、プロフィールの一番上に固定しておく投稿のことです。はじめて見に来た方が最初に読むため、公式LINEのご登録やご予約にもっともつながります。

1. 作って、公開する

固定投稿のコメント欄には、ご案内先のリンクが自動で付きます。ご案内先は公式LINE・Web予約・ホームページ・その他から登録でき、2つ以上あるときは「どこへ案内するか」をご自身で選べます（公式LINEの「お店・アカウント」→「ご案内先を選ぶ」、アプリでは誘導用URLの「ここへ案内する」）。

公式LINEから おすすめ
  1. メニューの「固定投稿を作る」を押す
  2. できあがった文章を確認する
  3. 「これで投稿する」を押す
アプリから
  1. ホームの「固定投稿をAIで作成」の「作成する」を押す
  2. 「AI投稿を生成」を押して、10〜30秒待つ
  3. 「今すぐThreadsに投稿」を押す

2. Threadsアプリでピン留めする（ここは共通です）

  1. Threadsアプリを開き、右下のアイコンから自分のプロフィールを表示する
  2. いま公開した投稿の右上の「…」を押す
  3. 「プロフィールにピン留め」を選ぶ（英語表示のときは Pin to profile）
  4. プロフィールの一番上に表示されれば完了。LINEの「ピン留めしました」を押す
できたかの確認　自分のプロフィールを開いたとき、その投稿がいちばん上にあれば完了です。
作っただけでは効果が出ません。公開して、Threadsアプリでピン留めして、はじめてお店の入口になります。ピン留めはThreads側の操作のため、Threads Studioからは行えません。
※ ピン留めできる投稿は1つだけです。別の投稿をピン留めすると、前のものは自動で外れます。

毎日の運用

1日1タップ

ここから先は、毎朝AIが投稿を作ります。届いた文章を見て、押すだけです。

公式LINEから おすすめ
  1. 届いたカードの文章を読む
  2. 「これで投稿する」で公開／「書き直す」で直す／「見送る」で今回は出さない
  3. 複数あるときは「すべて承認する」で一度に終わります
アプリから
  1. 左メニューの「投稿の確認・予定」を開く
  2. 「承認待ち」の投稿を確認する
  3. 「承認して投稿」を押す（直すときは「編集」）

「書き直す」では、直し方を選ぶほか、ご希望を文章でそのまま送れます（例：「料金の話は入れないで」）。

Meta AI呼びかけ投稿（自動・1日1件）
1日の投稿のうち1件として、「@meta.ai 新倉敷・玉島で肩こりに悩む人に、整体に通うメリットを伝えて」のような投稿を、朝〜昼に1件出します。 Meta AIがお店の名前を出してコメントで答えるので、投稿の下に会話ができ、届く人が増えます（実際に通常の投稿の数倍〜十数倍の表示になった例があります）。 依頼文は、はじめの設定で登録した地域・お客様像・店名から決まった型で作られます。止めたいときは「設定」からOFFにできます。この機能はプロプラン・ビジネスプランでご利用いただけます。ライトプランの方は、プランを変更するとその日からお使いいただけます。
※ @meta.ai はThreadsの仕様で段階的に提供されており、まだ使えないアカウントもあります。その場合はMeta AIの返事が付きません（投稿自体は出ます）。
毎朝7:40の「昨日の投稿結果」
前日にアカウントごとに何件公開されたかを、公式LINEにお知らせします。1件も公開されなかった日は「承認待ち◯件・取り消し◯件」のように理由も一緒に届くので、承認し忘れに気づけます。

困ったときは

こんなときこうしてください
投稿に @meta.ai の返信が付いたThreadsでは誰でも投稿の返信欄で @meta.ai を呼べるため、お店の投稿にMeta AIの返信が付くことがあります。消したいときは、その返信を長押し →「非表示」。@meta.ai はブロックできませんが、ミュートと「興味がない」は使えます。公式LINEで「Meta AIの返信」と送ると、同じ手順が届きます。
Threadsと連携できないまずThreadsアプリで、右下のアイコンから自分のプロフィールが出るかご確認ください。出ない場合はThreadsのアカウントがまだできていません（STEP3）。出るのに連携できない場合は、パソコンのブラウザで threads-studio.com を開いてお試しください。
連携画面から戻れないスマートフォンだとThreadsアプリに切り替わって止まることがあります。パソコンから、または通常のブラウザ（Safari・Chrome）で開いてください。
投稿が来ない「設定」で、自動投稿がONか・Threadsがつながっているか・お店の情報の登録が終わっているかをご確認ください。フリープランには自動投稿がありません。
申し込みボタンが効かないボタンの下に出る「お支払い画面を開く」のリンクを押してください。通常のブラウザで開き直すと確実です。
6桁の番号が届かない会員登録と同じメールアドレスを送っているか、迷惑メールフォルダに入っていないかをご確認ください。番号は10分で切れます。
写真や動画を入れたいいまは文章だけの投稿に対応しています。画像を付けたい投稿は、Threadsアプリからご自身で投稿してください。
連続投稿（ツリー）にしたいMeta社の追加審査の承認待ちです。承認されるまでは1投稿（500文字以内）でご利用ください。
コメントに返信したい返信の文案はAIが作ります。文案をコピーして、Threadsアプリから返信してください。送信機能は審査の承認待ちです。
それでも解決しない公式LINEのメニュー「使い方」→「担当者に聞く」から、そのままご質問ください。担当者がお答えします。

Threadsとの接続には60日の有効期限があります。期限が近づくとお知らせが出ますので、「接続を更新」を押してください。押さないと投稿が公開できなくなります。
