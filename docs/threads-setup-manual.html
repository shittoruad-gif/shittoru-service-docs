開設マニュアル

Instagramのアカウントをお持ちでない状態から、Threadsで毎日の集客投稿が自動で回るまで。順番どおりに進めれば、どなたでも設定できます。

全9ステップ 設定の合計 約30分 スマートフォンだけでも可

準備編STEP 1 - 3　アカウントをつくる
1

Instagramのアカウントを作る

所要 5分／すでにお持ちの方はSTEP2へ

ThreadsはInstagramのアカウントがないと始められません。お店のアカウントをお持ちでない場合は、先にこちらを作ります。

  1. スマートフォンに「Instagram」アプリを入れる
  2. 「新しいアカウントを作成」から、メールアドレスまたは電話番号で登録する
  3. ユーザーネームを決める。お店の名前と地域が分かるものにしてください（店名のローマ字と市区町村名を並べる形がおすすめです）
  4. プロフィール写真に、お店の外観かロゴを設定する
個人のアカウントは使わないでください。お店の投稿とご家族の写真が混ざってしまいます。お店専用に、新しく作ることをおすすめします。
2

Threadsのアカウントを作る

所要 3分

ThreadsはInstagramから作ります。新しくメールアドレスを登録する必要はありません。

  1. スマートフォンに「Threads」アプリを入れる
  2. 開くと、STEP1で作ったInstagramのアカウントが表示されます。それを選んで「ログイン」
  3. プロフィールをInstagramから引き継ぐか聞かれます。引き継いで問題ありません
  4. 「公開プロフィール」を選ぶ
非公開にしないでください。非公開にすると、フォロワー以外の方に投稿が届きません。集客のための発信ができなくなります。
3

Threadsのプロフィールを整える

所要 5分

投稿を見た方が最初に見る場所です。ここが空だと、興味を持たれても次につながりません。

  • 名前：お店の名前と地域（例：みらい整体院｜金沢市）
  • 自己紹介：どんな悩みの方が来ているか、営業時間、定休日
  • リンク：公式LINEの友だち追加URL、またはご予約ページ
公式LINEのURLは、あとでThreads Studioにも登録します。固定投稿のコメント欄に自動で付き、集客の入口になります。手元にご用意ください。
運用編STEP 4 - 9　Threads Studioの設定

ここからの設定は、公式LINEのトークからでも、アプリの画面からでも進められます。どちらか一方だけで大丈夫です。スマートフォンだけで完結する公式LINEをおすすめしています（Threadsの連携だけはパソコンが確実です）。

4

Threads Studioに会員登録する

所要 3分

  1. https://threads-studio.com を開く
  2. お名前・店舗名・メールアドレス・パスワードを入力する
  3. 紹介コードをお持ちの方は、そのまま入力する（お持ちでなければ空欄）
  4. 登録すると料金プランの画面が開きます。プランを選んでお申し込みください
お支払いのとき、メールアドレスはこの登録と同じものをご入力ください。違うアドレスだと、お支払いとアカウントが自動で結びつかず、有料機能が使えないままになります。
5

公式LINEとつなぐ

所要 2分

会員のアカウントと公式LINEを結び付けます。どちらから始めても結果は同じです。

公式LINEから おすすめ
  1. Threads Studioの公式LINEを友だち追加する
  2. トーク下のメニューで「登録済みの方はこちら」を押す
  3. 会員登録に使ったメールアドレスを、そのまま送る
  4. 届いた6桁の番号をトークに送る（10分間有効）
アプリから
  1. 左メニューの「設定」を開く
  2. 「LINEで通知を受け取る」の「LINE連携をはじめる」を押す
  3. 表示される「友だち追加する」から友だち追加する
  4. 画面に出た6桁のコードをトークに送る（10分間有効）
番号が届かないときは、会員登録と同じアドレスを送っているか、迷惑メールフォルダに入っていないかをご確認ください。
6

「はじめの設定」に答える

所要 10〜15分／全20問

お店のことを20問おうかがいします。答えた内容だけをAIは事実として使います。書いていない実績・料金・数字が投稿に出ることはありません。

公式LINEから おすすめ
  1. メニューの「はじめの設定」を押す
  2. 「お店の集客」か「個人にファンをつける」かを選ぶ
  3. 届く質問に、トークで順番に答える
アプリから
  1. ホームの「セットアップ状況」で「お店の情報を登録」の「登録する」を押す
  2. 「お店の集客」か「個人にファンをつける」かを選ぶ
  3. 画面の質問に順番に答える

あとから直したいときは、LINEの「お店の情報」／アプリの左メニュー「お店の情報を修正」から変更できます。

途中で手を止めても、それまでの回答は残ります。あとで「はじめの設定」を押すと「続きから」を選べます。
7

Threadsアカウントを連携する

所要 3分／パソコンからがおすすめ

STEP2で作ったThreadsに、投稿する権限をつなぎます。

公式LINEから
  1. メニューの「お店・アカウント」を押す
  2. 「Threadsアカウントの連携」を選ぶ
  3. 届いたリンクを開き、「Threadsと連携する」を押す
  4. Threadsの画面で内容を確認し、許可する
アプリから こちらが確実
  1. 左メニューの「Threads連携」を開く
  2. 「Threadsと連携する」を押す
  3. Threadsの画面で内容を確認し、許可する
この連携だけは、LINEの中のブラウザではうまく進めないことがあります。リンクを長押しして「デフォルトのブラウザで開く」を選ぶか、パソコンから操作してください。連携したいアカウントでThreadsにログインした状態で開いてください。
8

固定投稿を作って、ピン留めする

所要 5分／集客のいちばん重要な工程

固定投稿は、プロフィールの一番上に固定しておく投稿です。はじめて見に来た方が最初に読むため、公式LINEのご登録やご予約にもっともつながります。

1. 作って、公開する

公式LINEから おすすめ
  1. メニューの「固定投稿を作る」を押す
  2. できあがった文章を確認する
  3. 「これで投稿する」を押す
アプリから
  1. ホームの「固定投稿をAIで作成」の「作成する」を押す
  2. 「AI投稿を生成」を押して、10〜30秒待つ
  3. 「今すぐThreadsに投稿」を押す

2. Threadsアプリでピン留めする（ここは共通です）

  1. Threadsアプリを開き、右下のアイコンから自分のプロフィールを表示する
  2. その投稿の右上の「…」を押し、「プロフィールにピン留め」を選ぶ
  3. プロフィールの一番上に表示されれば完了。LINEの「ピン留めしました」を押す
作っただけでは効果が出ません。公開して、Threadsアプリでピン留めして、はじめてお店の入口になります。ピン留めはThreads側の操作のため、Threads Studioからは行えません。
9

毎日の運用

1日1タップ

ここから先は、毎朝AIが投稿を作ります。LINEに届いたカードを見て、押すだけです。

公式LINEから おすすめ
  1. 届いたカードの文章を読む
  2. 「これで投稿する」で公開／「書き直す」で直す／「見送る」で今回は出さない
  3. 複数あるときは「すべて承認する」で一度に終わります
アプリから
  1. 左メニューの「投稿の確認・予定」を開く
  2. 「承認待ち」の投稿を確認する
  3. 「承認して投稿」を押す（直すときは「編集」）

「書き直す」では、直し方を選ぶほか、ご希望を文章でそのまま送れます（例：「料金の話は入れないで」）。

投稿される時刻

15時
21時
22時

1回21時ごろ
2回15時ごろ／21時ごろ
3回15時ごろ／21時ごろ／22時ごろ

実測でいちばん反応が高い時間帯です。毎日ぴったり同じ時刻にならないよう、0〜29分のあいだでずらしています。お使いのうちに実績がたまると、その方の反応が高い時間帯へ自動で寄っていきます。

慣れてきたら公開前の確認をOFFにできます。確認なしで毎日自動で公開されるようになります。LINEの「設定」からでも、アプリの左メニュー「設定」からでも変更できます。投稿の回数（1日1〜3回）と長さも同じ場所で変えられます。

困ったときは

こんなときこうしてください
投稿が来ないLINEの「設定」で、自動投稿がONか・Threadsがつながっているか・お店の情報の登録が終わっているかをご確認ください。フリープランには自動投稿がありません。
連携から戻れないLINEの中のブラウザではなく、SafariやChromeなど通常のブラウザ、またはパソコンから連携してください。
申し込みボタンが効かないボタンの下に出る「お支払い画面を開く」のリンクを押してください。通常のブラウザで開き直すと確実です。
写真や動画を入れたいいまは文章だけの投稿に対応しています。画像を付けたい投稿は、Threadsアプリからご自身で投稿してください。
連続投稿（ツリー）にしたいMeta社の追加審査の承認待ちです。承認されるまでは1投稿（500文字以内）でご利用ください。
コメントに返信したい返信の文案はAIが作ります。文案をコピーして、Threadsアプリから返信してください。送信機能は審査の承認待ちです。
それでも解決しないLINEのメニュー「使い方」→「担当者に聞く」から、そのままご質問ください。

Threadsとの接続には60日の有効期限があります。期限が近づくとお知らせが出ますので、「接続を更新」を押してください。押さないと投稿が公開できなくなります。
