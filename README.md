# しっとる サービス資料（公開用）

Notionのサービス別ページから、ページ内プレビューで読み込むためのPDF置き場です。

- 生成元: `CODE/ts-deck/build_service_decks.cjs`
- 内容を直す手順: `service-catalog/data/services.json` または `ts-deck/deck_data.cjs` を直す → `node build_service_decks.cjs` → PDF化 → ここへコピーして push
- **push すれば Notion 側は自動で最新版になります**（Notionは外部URLを参照しているだけのため）

## ここに置かないもの
**スタッフ研修（社内用）は置きません。**原価・粗利・契約数を含み、Notionの該当ページは一般公開されているためです。
